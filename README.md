# Generative AI Learning Assistant

## Project Overview
The Generative AI Learning Assistant is an AI-powered application
designed to help students learn easily and effectively.
It uses Generative AI to provide answers, summaries, quizzes,
and personalized learning paths.

## Features
- AI-powered Question and Answer
- Automatic Text Summarization
- Quiz Generation
- Personalized Learning Paths
- Easy and Interactive Learning Experience

## Technologies Used
- Python
- Google Gemini AI
- Generative AI
- Python Libraries

## Project Modules
- main.py - Main application
- gemini_client.py - Gemini AI integration
- qna.py - Question and Answer module
- quiz_module.py - Quiz generation module
- summary_module.py - Text summarization module
- learning_path.py - Personalized learning path
- config.py - Configuration settings
- requirements.txt - Required Python packages
- .env - Environment variables

## Installation

1. Clone the repository.
2. Install the required packages:

   pip install -r requirements.txt

3. Configure your Gemini API key in the .env file.
4. Run the application:

   python main.py

## Usage
Run the application and use its AI-powered features
to ask questions, generate quizzes, summarize content,
and create personalized learning paths.
